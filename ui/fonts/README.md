# Interface fonts

| File | Role | Licence |
|---|---|---|
| `cinzel.ttf` | Headings, buttons, the wordmark: engraved, small-cap capitals | [OFL-cinzel.txt](OFL-cinzel.txt) |
| `alegreya.ttf` | Body text: warm storybook serif | [OFL-alegreya.txt](OFL-alegreya.txt) |
| `spectral-600.ttf` | The paper theme's headings (Field Notes, the job book: `ui/kit/paper_theme.gd`) | [OFL-spectral.txt](OFL-spectral.txt) |
| `ibm-plex-mono-latin-400-normal.woff2` | Code editor | [OFL-ibm-plex-mono.txt](OFL-ibm-plex-mono.txt) |

`cinzel.ttf` and `alegreya.ttf` are the Google Fonts variable-weight files (`Cinzel[wght].ttf`, `Alegreya[wght].ttf`),
copied unchanged from the main Rootward project's `game/ui/fonts/` on 2026-10-23 together with their licence texts.
Nothing is fetched at play time. This project does not depend on the main game: the files were copied once, like the
sandbox runtime.
