# Inactive source history

These files preserve authored work from rejected cutout and superseded interpolation experiments. They are excluded from Godot import and are not active build tools, runtime resources or alternate selected pipelines. Original paths and file hashes for the cutout experiment are recorded in `rejected-cutout/archive.json`.

The active character pipeline uses painted shared-frame skins: `pipeline/character-template.json`, `pipeline/character-catalog.json` and `scripts/art.sh`. Do not restore an archived rig to the game based on its technical tests.
