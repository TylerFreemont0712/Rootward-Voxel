# Anonymous cast silhouettes — v3

Direct user revision, 2026-11-02: use varied existing character/villager sprites, blacked out and selected randomly.

`appearances.json` registers thirteen profiles from eleven approved complete atlases. Both casts contribute adult silhouettes. The boy and smaller Mira/Tessa profiles supply children. This is a source selection, not a repaint. Every original painting and alpha pixel remains intact. The common template still owns gait, anchors, neutral pose, breath and blink.

Build through `scripts/art.sh`. The existing phantom builder flattens RGB and records exact source/output hashes; the runtime applies charcoal 0.20 at 98% opacity. `groups` owns compatible pools. The presenter uses shuffled bags per visit and new choices for later tram services; this cosmetic randomness never changes movement decisions.

Previous v1/v2 source packs are retained, unselected. No external service is required to build or play these profiles.
