# Seaside background houses — v1

Five residential massing concepts for the town beyond the playable street edges. D is a four-storey narrow lodging house with attic; E is a broad three-storey apartment house; F is a compact two-storey home with loft; G is a low cottage with loft; H is one joined three-/two-storey terrace asset. Their names are working labels.

Each selected plate shows the front/right and opposite rear/left at the same approximate 31° orthographic elevation as the game. These are design references, not measured elevations. Individual plates fit their own canvases rather than sharing one common scale.

Selected images:

- `D-lantern-row-lodging-house-v2.png`
- `E-saltwind-apartment-house.png`
- `F-rosewash-lane-house.png`
- `G-shingle-court-cottage.png`
- `H-eaveside-terrace-pair-v2.png`

The first D/H attempts did not have the requested taller floor count. Targeted second passes add one complete floor to D and to H’s taller half. Both first attempts remain preserved. As with generated edits, the second versions redraw pixels rather than preserving an exact unchanged subregion.

`prompts.json` records the selected five plates and all seven attempts, including the exact prompts, reference/output hashes and original imagegen output paths. Individual `.generation.json` records accompany every image. References are the approved Guildhall Square and the previous sail-loft/bathhouse plates. All were generated using built-in imagegen, without CLI/API fallback or manual pixel editing. Model identifier and seed were not exposed. Documentation copies are unchanged PNG copies.

The accompanying [texture pack](textures/README.md) supplies five surfaces in three colours each, in its own folder and the normal `scripts/art.sh` build. No new building model, collision footprint, placement, quest or runtime backdrop is selected by these concept images. An approved design should be modelled and adopted through the existing Blender/world catalog workflow.
