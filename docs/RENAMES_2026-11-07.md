# Naming tidy-up — 2026-11-07

At the user's request the code, assets and content were reorganised so the names say what things are now that
Sparks & Machines is the only journey. The rules this set up are in [NAMING.md](NAMING.md). Nothing was repainted
or remodelled; files were moved and renamed, references rewritten, and old saves are migrated as they load.
`art/source/` (versioned history) and `evidence/` (records) were left where they were.

Use this table to find an old name from a review, a commit message or a memory note.

request that was current (`20261102T160426-a4fba942`, the tailor's exterior) had its catalog-entry fingerprint
re-recorded, with a history line saying why: its source and runtime fingerprints still match exactly, so it stays
finished. The other requests naming these models were already marked "changes requested" and are unchanged.

## Saves

- The save file is now `rootward.save.sparks-and-machines.json` (development: `rootward.save.dev.sparks-and-machines.json`).
  If only an old `kindle_hollow.save.*` file exists, it is read; the first save under the new name renames the old
  file to `.bak` so it is never read again, and starting over does the same.
- `app/save_migration.gd` renames retired ids in a save as it loads (`shop-bookshop`, `bookshop`,
  `bookshop-window-lamp`). It only touches whole strings and dictionary keys, never prose.
- Checked on a copy of a real save from 2026-11-06: it loaded, every old id was renamed, the tailor's lamp state
  carried over, and Continue resumed on Spindle Lane at the saved cell. The original file was not touched.
