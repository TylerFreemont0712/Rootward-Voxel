The selected square concept, approved 2026-10-29.

![Guildhall Square](art/guildhall-square.png)

A mainly flat city square with a prominent amber power beacon, a grand guild hall and open space for future building and world changes. Merchant and postal frontages frame the edges; the uphill approach continues off-screen toward Nell’s workshop.

The image is copied unchanged from the [authored concept source](../../../art/source/world/sparks-square/v3-guildhall-square/E-guildhall-square-v2-offscreen-hill.png). Created with the built-in imagegen tool; the [exact edit prompt](../../../art/source/world/sparks-square/v3-guildhall-square/offscreen-hill-prompt.json) and [provenance](../../../art/source/world/sparks-square/v3-guildhall-square/offscreen-hill-provenance.json) remain with that source. This records the art direction. The playable square was rebuilt to it on 2026-10-29: see the [Guildhall Square review](../../../pipeline/reviews/2026-10-29-guildhall-square.md).
