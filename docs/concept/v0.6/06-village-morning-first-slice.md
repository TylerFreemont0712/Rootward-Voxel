# Village Morning: first slice — 2026-10-25

The user requested a fresh village concept, developed step by step while retaining the existing level. The first implemented slice is waking at home and teaching movement keys, with a choice of handwritten code or simple ready-made blocks. New buildings and characters are later work.

**Implemented:** New journey selects Kindle Hollow or Village Morning, each with independent saved progress. Village Morning starts beside the bed in a bespoke furnished room, introduces Hotaru’s greeting notebook, then movement, and asks the player to connect four directions, Preview, Apply and practise them. The guided editor has four fixed event blocks with dropdowns; the manual editor uses real Python. Both use the same WASI and atomic proposal contract. The completed lesson opens a basic exterior lane and the ordinary saved return-home flow.

**Presentation:** existing approved boy and camera, existing adopted furniture/materials and one existing exterior cottage. The new cutaway room has its own windows, panelling, bedside alcove and arrangement. The waking moment is currently prose and a fade into the room; there is no new sleeping/waking animation.

**Deferred:** the rest of the village, new buildings/residents, further quests, draggable programming blocks, inventories and general outdoor-region travel. Review this first morning together before extending its scope.
