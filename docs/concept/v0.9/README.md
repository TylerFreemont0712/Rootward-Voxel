# v0.9 — The tablet curriculum

[Learning the tablet: Hotaru's hand-held introduction](tablet-tutorial.md) — the first lesson of the saving-as-git
curriculum: the home key, the Terminal and its commands, Saves, Settings; skippable in one answer; built to grow as
apps are added.

v0.9 turns the field tablet (the pause menu, the git terminal and the saves browser that replaced autosave on
2026-11-18, [design](../save-vcs/PLAN.md)) into something the game teaches rather than something the player must
discover. Everything in it uses real vocabulary: what Hotaru says about `git status`, `git add`, `git commit` and
`git switch` is what those commands mean at work.

The current [handoff](../../PROJECT_HANDOFF.md), the [interface guide](../../../pipeline/UI.md) and the
[runtime story](../../../content/journeys/sparks-and-machines.json) describe what is implemented; the
[dialogue principles](../v0.7/07-dialogue.md) govern Hotaru's voice here as everywhere.
