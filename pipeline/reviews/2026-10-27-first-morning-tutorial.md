# First morning, job book and dialogue — 2026-10-27

Sparks & Machines now starts the traveller by the bed. Nell’s note is a separate outlined desk asset under the mug; clicking it or using F walks to it and opens the note, and deliberately putting it away records the inspection and removes the paper. Clicking the printer opens the first lesson. Closing the note early keeps it in the room. The ticket shows the three steps and opens a job book containing reached jobs from both visited floors.

The desk page begins with an editable message block and can switch to Python. Both use the real bounded WASI runner; block edits generate Python and custom Python drafts survive mode changes. Test renders the actual output above the player as a ghost, including other names. Speak commits only the tested proposal; a greeting addressed to Hotaru rings the printer’s bell. Her waking conversation gives the traveller the small hand terminal on the desk, providing the story handoff for the workshop pages. The current morning-round page introduces a list and loop one lamp at a time. Reusable zone terminals, new zone indicators and later programming lessons are not implemented.

Default dialogue speed is 25% faster, and existing non-default preferences remain saved.
