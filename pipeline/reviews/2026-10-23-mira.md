# Mira, an authored female character — 2026-10-23

Mira is a new female lantern cartographer with an espresso wavy bob, brass hair clips, warm brown skin, plum tunic coat, ochre scarf, sage cuffs, moss trousers and chestnut boots. This is a complete appearance for feedback, selectable alongside the approved original, which remains the default.

## Source and animation

The [source record](../../art/source/characters/mira/v1/authoring.json) and [exact built-in imagegen prompts](../../art/source/characters/mira/v1/prompts.json) describe the three image edits. The original SE and NE nine-pose sheets supplied the strict pose and camera references. Mira's generated SE sheet supplied the identity reference for her NE sheet. The original character's paintings are unchanged.

The new version contains nine 418 px cells per directional sheet: eight corresponding walk poses and one neutral. SW mirrors each SE cell and NW mirrors each NE cell, without reordering. An additional imagegen eye edit is composited only inside two feathered eye polygons; all other neutral pixels stay unchanged. The SW blink is an exact mirror.

`pipeline/prepare_directional_walk.gd` packed the sources with integer registration. `scripts/art.sh` compiled `assets/characters/skins/mira.png` and the shared library. The shared template was not changed: four views, eight walk frames at 16 FPS, neutral/blink slots, `[192,420]` foot origin, 1.45 world height, 3.6-second breathing, and 120 ms front blinks every 6–7 idle seconds. Rear views only breathe. Mira has no private motion settings.

## Trying Mira

Open **Character** from the title or pause menu, then select **Mira** below the portrait. **Original** switches back. Selection changes both the portrait and world actor and is remembered in settings. It preserves the player's name, world state, code and progress. Missing or invalid preferences load the original. The twilight tint remains an authoring example, hidden from this picker.
